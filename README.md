# مُشغّل الروابط اليومي (Daily Tabs Opener)

إضافة لمتصفح جوجل كروم (والمتصفحات المبنية على Chromium) تقوم بفتح مجموعة من الروابط المحددة مسبقاً تلقائياً عند فتح المتصفح لأول مرة في اليوم.

## المميزات
## المميزات
* **التشغيل التلقائي مرة واحدة يومياً:** توفير الوقت بفتح أدوات العمل ومواقعك اليومية تلقائياً.
* **المزامنة السحابية:** مزامنة الروابط والإعدادات عبر جميع أجهزتك باستخدام حساب Google الخاص بك (`storage.sync`).
* **دعم الروابط والنصوص:** يمكنك كتابة رابط مباشر أو كتابة كلمة ليتم البحث عنها في Google تلقائياً.
* **إدارة مرنة واحترافية:** * السحب والإفلات (Drag & Drop) لترتيب أولوية فتح الروابط.
  * إمكانية تصدير واستيراد القوائم (Backup/Restore).
  * زر إيقاف مؤقت لتعطيل عمل الإضافة دون الحاجة لحذف الروابط.
* **تجربة مستخدم هادئة:** تفتح الروابط كعلامات تبويب مثبتة (Pinned) وفي الخلفية.
* **وصول سريع:** فتح صفحة إدارة الروابط بضغطة واحدة مباشرة على أيقونة الإضافة في شريط المتصفح.
* **خصوصية تامة:** جميع الروابط والبيانات تُحفظ محلياً على جهازك.

## طريقة التثبيت (للمطورين والتجربة)
1. قم بتحميل جميع ملفات الإضافة في مجلد واحد.
2. افتح متصفحك واذهب إلى صفحة الإضافات `chrome://extensions/`.
3. فعّل **وضع المطور (Developer mode)** في أعلى الشاشة.
4. اضغط على **تحميل إضافة تم فك حزمها (Load unpacked)** واختر المجلد.

## طريقة الاستخدام
1. اضغط على أيقونة الإضافة في شريط المتصفح العلوي.
2. ستفتح لك صفحة "إدارة الروابط اليومية".
3. قم بإضافة الروابط التي تريد فتحها بشكل يومي.
4. في المرة القادمة التي تفتح فيها المتصفح في يوم جديد، سيتم فتح جميع الروابط المسجلة تلقائياً.

## التقنيات المستخدمة
* Manifest V3
* Service Workers (`background.js`)
* Chrome Storage API
* HTML / CSS / Vanilla JavaScript
